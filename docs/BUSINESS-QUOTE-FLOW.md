# 商机报价单流程 V1

> 状态：已实现（2026-11-01）

## 业务边界

- 客户或线索转商机时，只填写商机备注，不关联产品、尺寸和金额。
- 产品、数量、报价、洞口尺寸、生产参数和下单表全部放在报价单里。
- 一个商机可以创建多张报价单，用于比较不同方案。
- 每张报价单可以包含多条产品明细；每条明细只需关联产品、上传对应 `.xlsx` 下单表和填写备注。
- 一个商机只能有一张客户已确认的报价单。
- 只有客户已确认的报价单可以生成订单。

## 流程

```text
线索 / 客户
  ↓ 转商机，只填备注
商机
  ↓ 创建报价单
报价单
  ├─ 选择产品
  ├─ 下载该产品的 Excel 模板
  ├─ 上传本次修改后的下单表
  ├─ 保存前校验 Sheet1 的 A1 是否与产品模板一致
  ├─ 自动识别 Sheet1 的合计金额并预填报价
  └─ 生成保留表格式的下单表数据区域图片
  ↓ 微信发客户，记录关联报价单的跟进履历
客户确认报价单
  ↓ 报价单锁定，商机成交
以该报价单生成订单
  ↓
填写整单优惠、运费、定金、物流和收货信息
  ↓
待支付 → 已支付定金 → 生产中 → 已支付尾款 → 待发货 → 已发货 → 已完成
```

## 报价单状态

| 状态 | 含义 | 可编辑 | 可确认 | 可生成订单 |
|---|---|---|---|---|
| `draft` | 报价 | 是 | 所有产品均已上传下单表时可发送客户确认 | 否 |
| `pending` | 待客户确认 | 否 | 是 | 否 |
| `confirmed` | 客户已确认 | 否 | 否 | 是，且一个商机仅一张 |
| `void` | 历史 | 否 | 否 | 否 |

报价单发出后，如客户要求调整，可从「待客户确认」点击「重新报价」退回 `draft`，修改产品和价格后再次发送。客户已确认或历史报价单不能退回。

## 商机与标签

- 从线索或客户转商机时只弹出确认框，不要求填写备注；线索转化会明确提示原线索不再显示在线索池。
- 商机页不再展示商机备注，也不提供备注编辑入口。
- 客户名称后展示「报价单 N」系统标签，以及该商机的手动/自动标签；点击 `＋` 添加手动标签。
- 手动标签可删除，`报价单 N`、`待确认`、`金额 ¥xxx` 等系统/自动标签不可删除。
- 报价单发客户确认后生成「待确认」和当前报价金额标签；重新报价、作废、删除或客户确认后自动清理待确认标签。

## 履历

- 创建报价单时，自动写一条「报价单」履历。
- 添加或修改报价产品、上传或替换下单表时，记录产品编码/名称、类型、型号、驱动方式、数量、报价金额、识别合计、备注、下单表文件名、Sheet1 行列信息及表格内容缩略图。
- 报价单发客户确认时，履历展示整张报价单及所含产品的完整明细，并保留每张下单表的内容缩略图和下载入口。
- 客户确认报价单时，写「客户确认」履历。
- 商机里记普通跟进时，可关联当前商机的任一张报价单。
- 关联后的履历显示报价单编号。

## 下单表

- 只接收 `.xlsx`，单个文件最大 20MB。
- 只使用第一个工作表 `Sheet1`，其他工作表忽略。
- 使用 Sheet1 的 `A1` 与所选产品原始模板的 `A1` 比对，不一致时禁止保存。
- 自动从 Sheet1 中带“合计 / 总计 / 总金额”的区域识别大于 0 的金额并预填报价，报价金额可手动修改。
- 保存产品前先完成识别并生成数据区域 PNG；图片读取列宽、行高、合并单元格、字体、颜色、边框和对齐方式。
- 商机页展示下单表缩略图，点击缩略图在当前页查看大图。
- 页面同时提供产品原始模板下载和本次已上传下单表下载。
- 报价单确认后，产品、价格、生产参数和下单表均锁定。

## 订单

- 订单记录来源报价单编号。
- 订单产品明细和产品快照来自客户确认的报价单。
- 优惠只作用于产品合计，运费独立记录并计入订单应收。
- 新流程生成的订单直接进入「待支付」，因为客户已在报价单阶段确认。
