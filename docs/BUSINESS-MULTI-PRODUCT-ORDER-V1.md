# 多产品商机与订单确认 V1

> 状态：已实现（2026-11-01）

## 业务口径

- 一个商机可以包含多条产品明细。
- 同一产品、同一尺寸和生产参数使用数量；尺寸或参数不同必须拆成两条明细。
- 优惠只作用于产品合计，不修改每条产品的单价。
- 运费单独记录并计入订单应收，不作为产品金额。
- 优惠和物流条件可以在微信中协商，不要求印在客户收到的下单表上。
- 下单表用于客户确认产品、数量和参数；微信聊天用于确认优惠、运费等商务条件。

## 金额公式

```text
产品合计 = Σ（明细单价 × 数量）
产品应收 = 产品合计 - 整单优惠
订单应收 = 产品应收 + 运费
尾款 = 订单应收 - 定金
```

约束：

- `0 ≤ 整单优惠 ≤ 产品合计`
- `运费 ≥ 0`
- `0 ≤ 定金 ≤ 订单应收`
- 押金与尾款必须按订单应收结清，产品金额与运费在报表和详情中分开显示。

## 状态流

```text
商机草稿
  ↓ 产品明细确认、微信协商优惠与物流
生成订单（待客户确认）
  ↓ 微信发送下单表，客户确认产品及协商条件
记录客户确认（可上传截图）
  ↓
待支付 → 已支付定金 → 生产中 → 已支付尾款 → 待发货 → 已发货 → 已完成
```

生成订单后商机锁定；只有记录客户确认后，商机才进入「成交」，避免未确认订单提前进入成交统计。

## 页面行为

- 商机详情新增「产品明细」表，可添加、编辑、删除产品。
- 编辑明细可维护洞口尺寸、生产参数、数量、单价和备注。
- 生成订单时展示产品明细，填写整单优惠、优惠说明、运费、物流与收货信息。
- 订单详情分开展示产品合计、整单优惠、产品应收、运费和订单应收。
- 待客户确认的订单可记录微信确认说明并上传最多 3 张确认截图。
- 客户确认后订单进入待支付，商机同步进入成交。

## 数据快照

- `deal_items`：商机当前产品工作清单。
- `order_items`：生成订单时冻结的产品明细。
- `orders.product_total`：产品合计。
- `orders.discount_amount`：整单优惠。
- `orders.product_payable`：优惠后产品应收。
- `orders.logistics_fee`：运费。
- `orders.amount`：订单应收（产品应收 + 运费）。
