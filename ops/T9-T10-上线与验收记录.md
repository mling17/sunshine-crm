### 与计划步骤的唯一偏差（有意为之）
计划 T9 步骤 4「先 `systemctl enable --now crm-api`，步骤 5 再改密码并重启」会让首个种子用户用默认 `change-me` 落库，
而 `seed_admin_if_needed()` 在 `users` 非空时**不会覆盖**密码（设计如此），重启也改不了线上密码。
因此把「写 `.env`」提前到首次启动之前：一次启动即种出强密码账号，避免先留弱口令再人工改库。
其余步骤顺序与计划一致。

## 5. 回滚口径（仍按 OPS 手册 §5，三粒度）

```bash
# a) 只回滚服务（nginx 侧 /crm/ 会 502，不影响其它服务）
systemctl disable --now crm-api
# b) 回滚 nginx（唯一一次改动就在这个备份里）
cp /root/nginx/conf.d/default.conf.bak-20261029-183951 /root/nginx/conf.d/default.conf
docker exec nginx nginx -t && docker exec nginx nginx -s reload
# c) 回滚数据（先留现场再覆盖）
systemctl stop crm-api
cp /opt/data/crm/crm.db /opt/data/crm/crm.db.pre-rollback-$(date +%s)
tar xzf /opt/data/crm/backups/<日期>/crm-*.tar.gz -C /tmp/crm-restore
cp /tmp/crm-restore/crm.db /opt/data/crm/crm.db && rsync -a /tmp/crm-restore/uploads/ /opt/data/crm/uploads/
systemctl start crm-api && curl -s http://127.0.0.1:8010/health
```
